ClipLoop Developer Docs

Programmable video generation for developers and product teams. Generate promo videos, scene specs, and video artifacts from an API.

✨ Current API

The first public endpoint is Weekly Promo — generate a short-form promo video from a URL and a weekly update.

ClipLoop is an API-first platform. Send structured inputs, receive video artifacts. No browser UI required. The dashboard is one consumer of the API — you can build your own.

Key concepts

API KeyScoped bearer token for authentication. Created in the dashboard.
CreditsPay-per-use unit. 5 generation credits per weekly promo API call.
Idempotency KeyPrevents double charges. Same key + same body = cached result.
ScopeAPI keys require weekly_promo:generate for the promo endpoint.

Quickstart

Get your first weekly promo generated in under 5 minutes.

POSThttps://app.cliploop.site/api/public/weekly-promo
  1. Create a free account at app.cliploop.site
  2. Open Settings → API Keys in the dashboard
  3. Click Generate API key and copy the raw key immediately
  4. Make your first request using the examples below
  5. Track usage in the Usage tab
⚠️ The raw API key is shown only once at creation. Store it securely. Only the prefix is stored server-side.

Authentication

All public API endpoints require a Bearer API key.

Authorization: Bearer clp_live_•••••••••••••••

Scope

The weekly promo endpoint requires the scope weekly_promo:generate. Keys are scoped at creation time.

Security rules

  • Never expose raw API keys in frontend code or client-side apps
  • Make API calls from your backend or server-side environment only
  • Rotate keys periodically via the dashboard
  • Revoke compromised keys immediately

Idempotency

Prevent duplicate charges with Idempotency-Key. Include a unique key (minimum 8 characters) in every request header.

Idempotency-Key: my-campaign-launch-v2

Behavior

ScenarioResult
Same key + same bodyReturns cached response, no re-charge
Same key + different body409 IDEMPOTENCY_CONFLICT
Key missing400 IDEMPOTENCY_KEY_REQUIRED
Key in use (job running)409 IDEMPOTENCY_IN_PROGRESS
💡 Use a deterministic key per content piece (e.g., weekly-promo-{date}-{appName}) so retries are safe and intentional.

Credits & Billing

ClipLoop uses a pay-per-use credit model. No subscriptions required.

Credit costs

ActionBucketCost
Weekly Promo API callGeneration5 credits
Video renderRender1 credit
Copy generation (chat)Generation1 credit
Video generation (chat)Generation1 credit

Insufficient credits

When credits are exhausted, the API returns 402 CREDITS_INSUFFICIENT. Top up via the Billing page in the dashboard.

Monthly grants

Free tier includes monthly generation and render credits. Balances are visible in the dashboard.

Request Body

The weekly promo endpoint accepts a JSON payload describing your app and this week's update.

{ "appName": "ClipLoop", "appWebsiteUrl": "https://cliploop.site", "weeklyUpdate": "ClipLoop now has a public API for weekly promo generation.", "targetAudience": "indie app builders and SaaS founders", "callToAction": "Try ClipLoop", "channel": "x", "tone": "clear, sharp, builder focused" }
FieldTypeRequiredDescription
appNamestring✅Your app or product name
appWebsiteUrlURL—Website for brand extraction
weeklyUpdatestring✅What's new this week (8–500 chars)
targetAudiencestring—Primary audience description
callToActionstring—Desired CTA text
channelenum✅One of: instagram, tiktok, whatsapp, x
tonestring—Promo tone (e.g., professional, energetic)

Response Body

On success, the API returns a JSON object with the generated script, scene plan, and artifact metadata.

{ "artifactId": "clp_abc123", "previewUrl": "https://cdn.cliploop.site/...", "downloadUrl": "https://cdn.cliploop.site/.../download", "artifactUrl": "https://cdn.cliploop.site/.../video.mp4", "script": { "hook": "Stop scrolling if your team still uses email...", "body": ["We built MyApp for teams that move fast."], "caption": "Big update! MyApp v2 is here.", "cta": "Try it free for 14 days at myapp.com" }, "scenePlan": ["Scene 1: Quick-cut problem montage"], "creditsCharged": 5, "idempotencyKey": "my-campaign-launch-v2", "renderStatus": "rendered" }
FieldDescription
artifactIdUnique artifact identifier
previewUrlPreview image (may be null if rendering deferred)
downloadUrlDirect download link for the video file
artifactUrlCDN URL for the rendered video
scriptFull script object (hook, body, caption, cta)
scenePlanOrdered list of scene descriptions
creditsChargedCredits deducted from your balance
idempotencyKeyEcho of the key used for this request
renderStatusOne of: rendered, renderer_unavailable, pending
Renderer fallback: If the video engine is unavailable, the API returns the script and scene plan with renderStatus: "renderer_unavailable". You can retry later or use the script output directly.

Examples

cURL

curl -X POST https://app.cliploop.site/api/public/weekly-promo \\ -H "Authorization: Bearer $CLIPLOOP_API_KEY" \\ -H "Idempotency-Key: $IDEMPOTENCY_KEY" \\ -H "Content-Type: application/json" \\ -d '{ "appName": "ClipLoop", "appWebsiteUrl": "https://cliploop.site", "weeklyUpdate": "ClipLoop now has a public API for weekly promo generation.", "targetAudience": "indie app builders and SaaS founders", "callToAction": "Try ClipLoop", "channel": "x", "tone": "clear, sharp, builder focused" }'

JavaScript (fetch)

const generatePromo = async (input) => { const res = await fetch("https://app.cliploop.site/api/public/weekly-promo", { method: "POST", headers: { "Authorization": `Bearer ${process.env.CLIPLOOP_API_KEY}`, "Idempotency-Key": `promo-${Date.now()}`, "Content-Type": "application/json" }, body: JSON.stringify(input) }); if (!res.ok) throw new Error(`HTTP ${res.status}`); return res.json(); };

Node.js

import fetch from "node-fetch"; const generatePromo = async (input) => { const res = await fetch("https://app.cliploop.site/api/public/weekly-promo", { method: "POST", headers: { "Authorization": `Bearer ${process.env.CLIPLOOP_API_KEY}`, "Idempotency-Key": `promo-${Date.now()}`, "Content-Type": "application/json" }, body: JSON.stringify(input) }); const data = await res.json(); if (!res.ok) throw new Error(data.error?.message || res.statusText); return data; };
