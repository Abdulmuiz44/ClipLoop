Quickstart

Generate your first weekly promo video in under 5 minutes.

Steps

  1. Create a free account at app.cliplane.site
  2. Open Settings → API Keys in the dashboard
  3. Click Generate API key and copy the raw key immediately
  4. Make your first request using one of the examples
  5. Track usage in the Usage tab

Endpoint

POSThttps://api.talocode.site/v1/cliplane/weekly-promo
