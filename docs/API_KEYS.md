# ClipLane API Keys

Get your ClipLane API key from the [ClipLane dashboard](https://dashboard.talocode.site/products/cliplane).

## What you need a key for

The SDK can generate scripts and storyboards locally without an API key.

Hosted rendering and other remote workflows require an API key.

## Important

- Do not hardcode secrets into source files.
- Prefer environment variables such as `TALOCODE_API_KEY`.
- Keep keys server-side.
