# Release Demo Video

ClipLane release videos are kept as generated assets, not committed binaries.

## SDK demo

- Source: `apps/cliplane-sdk-demo-video/render-demo.mjs`

## Notes

- Use a release-quality MP4 for GitHub Releases.
- Keep the video local-first and code-focused.
- Prefer ffmpeg fallback if a Remotion renderer is not available or reliable.
