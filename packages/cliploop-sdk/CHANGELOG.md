# Changelog

## 0.1.0

- Reworked the SDK around ClipLoop’s open-source, local-first mission.
- Added `ClipLoop` for optional hosted API usage.
- Added `ClipLoopLocal` for deterministic local generation without an API key.
- Documented `cliploop.site` API key flow.
- Added script, storyboard, render job, and X export workflow methods.
