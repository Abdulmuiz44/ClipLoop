# Changelog

## 0.1.0

Initial release of ClipLane as a local-first open workflow layer.

### Added

- `cliplane init`
- `cliplane script --update "..."`
- `cliplane storyboard --script ./script.md`
- `cliplane render`
- `cliplane export x`
- `cliplane doctor`
- local `.cliplane/` workspace storage
- FFmpeg render fallback
- provider scaffolding for future render backends
