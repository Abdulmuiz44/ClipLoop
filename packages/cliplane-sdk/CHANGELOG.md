# Changelog

## 0.1.0

- Reworked the SDK around ClipLane's open-source, local-first mission.
- Added `ClipLaneLocal` for deterministic local generation without an API key.
- Retained `ClipLoop` as a legacy hosted API compatibility client.
- Documented `cliploop.site` API key flow.
- Added script, storyboard, render job, and X export workflow methods.
