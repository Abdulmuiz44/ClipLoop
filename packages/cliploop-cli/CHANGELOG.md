# Changelog

## 0.1.0

Initial release of ClipLoop as a local-first open workflow layer.

### Added

- `cliploop init`
- `cliploop script --update "..."`
- `cliploop storyboard --script ./script.md`
- `cliploop render`
- `cliploop export x`
- `cliploop doctor`
- local `.cliploop/` workspace storage
- FFmpeg render fallback
- provider scaffolding for future render backends
